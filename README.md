# python-noise-removal-signal-processing
Python Noise Removal Using Digital Signal Processing

1. Project Introduction

This project focuses on removing unwanted noise from a signal using Python programming.

I developed this project based on the knowledge I gained from my third-year university module, Data Acquisition and Signal Processing.

The project demonstrates how digital filtering techniques can be used to improve signal quality.

2. Project Objectives

- To understand the effect of noise on signals.
- To apply a Butterworth filter for noise reduction.
- To investigate the effect of different cutoff frequencies.
- To compare noisy and filtered signals.
- To apply theoretical signal processing knowledge using Python.

3. Tools and Technologies

- Programming Language: Python
- Signal Processing: Butterworth Filtering
- Platform: Python development environment
- Version Control: GitHub

4. Methodology

The project was carried out through the following steps:

1. Creating or obtaining an input signal.
2. Adding noise to the signal.
3. Applying a Butterworth filter.
4. Testing different cutoff frequencies.
5. Comparing the original, noisy and filtered signals.
6. Observing the changes in signal quality.

5. Results

The results demonstrate how filtering can reduce unwanted noise in a signal.

Different cutoff frequencies were tested to observe their effects on the filtered signal.

Result Graphs

The graphs generated during the project are available in the "results" folder.

6. Conclusion

This project helped me understand the practical application of digital signal processing using Python.

I gained experience in signal filtering, noise reduction and analysing signal behaviour under different cutoff frequencies.

It also helped me connect the theoretical knowledge gained from my university studies with practical programming.
